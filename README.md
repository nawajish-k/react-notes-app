# 📝 React Notes App

A Notes application built with React. Users can create, edit, delete, and search notes. Notes are automatically saved in the browser using Local Storage, so they persist even after refreshing the page.

## ✨ Features

- ➕ Add new notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 🔍 Search notes by title or details
- 💾 Automatic Local Storage persistence
- 🔄 Load saved notes on page refresh
- 🚫 Prevent empty notes from being added
- 📱 Responsive layout
- 📄 Empty state messages
  

## 🛠️ Built With

- React
- JavaScript (ES6+)
- Tailwind CSS
- React Hooks
  - `useState`
  - `useEffect`

## 📸 Current Functionality

- Create notes with a title and description.
